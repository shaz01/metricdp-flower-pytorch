# For experiment READMEs:

- **The Result answers the Question directly.**
- **Motivation and things known beforehand go in the Question,** not the Result.
- **No raw result tables.** Use only the few numbers the argument needs.
- **Limitations go under `## Caveats`,** separate from the Result.
- **Fold supporting detail** (tables, explanations) with `<details>`.
- **Write it like we talk:** short, direct, the claim first.
- **Drop sections nobody reads,** like Runs and Files.
- **Cut lists and exceptions** that don't change the conclusion.
- **Say what it means for past work,** for example: "old non-IID results aren't non-IID".
- **Only claim what this experiment's runs produced** as its result.
- **Use real names,** not "owner" or "teammate".
