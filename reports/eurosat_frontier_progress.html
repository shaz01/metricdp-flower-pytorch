Limitations

  • Old-cohort runs record torch in run metadata but no pip freeze or full runtime capture; exact old environments are unknown. That is a reproducibility limitation, not grounds to discard them.
  • Seed 44 pairs an old-runtime IN with pinned-runtime OUTs for targets 4–9. It is labeled, not assumed equivalent; no formal statistical equivalence between runtimes is established (see panel 3).
  • Vanilla has only seed 42, pinned runtime only; it is a reference point, not a runtime-matched baseline.
  • 2–3 seeds × 10 correlated targets: descriptive only; no confidence intervals, no privacy certification, and attack metrics near or below .5 are not proof of privacy.
  • Pilot: seed 42 only, own RNG/clipping; the utility screen used the same server test split that is reported here.
